Project Description:
This project is a personal portfolio website built using HTML, CSS, and JavaScript.

---Setup Instructions 
1-Open the project folder in VS Code.
2-Make sure all files are organized (index.html, css, js, assets).
3-Right-click on index.html.
4-Click "Open with Live Server" (VS Code extension).
5-The website will open in your browser.
