

---Project Description

-This project is a personal portfolio website built using HTML, CSS, and JavaScript.
It showcases my projects, skills, and contact information. The website also includes interactive features such as filtering projects, dark mode, API integration, and form validation.


---Setup Instructions 
-Open the project folder in VS Code.
-Make sure all files are organized (index.html, css, js, assets).
-Right-click on index.html.
-Click "Open with Live Server" (VS Code extension).
-The website will open in your browser.
